# Identidade visual

Tema **claro**, linhas de design modernas e elegantes. Paleta escolhida pelo
usuário em 16/jun/2026 (a partir de 3 opções em mockup): **índigo moderno**.

## Paleta — índigo moderno

| Token | Hex | Papel |
|---|---|---|
| `bg` | `#F5F6FB` | fundo da tela (claro levemente azulado, não branco clínico) |
| `panel` | `#FFFFFF` | superfícies: faixa da pauta, botões |
| `ink` | `#222633` | texto, pauta, clave, notas |
| `muted` | `#8A8FA0` | texto secundário, bordas, estados inativos |
| `accent` | `#5A5BE0` | primária (índigo): linha de acerto e botão da posição esperada |
| `accent2` | `#159E91` | momentum/combo (barra + multiplicador) — cor que "esquenta" |
| `btn` | `#EDEFF8` | face do botão de posição inativo |

## Papéis de cor

- `accent` é a voz do jogo: linha de acerto + botão da posição correta.
- `accent2` é a cor do momentum/combo — liga a tela principal ao protótipo de
  momentum (`prototypes/momentum-demo.html`).
- Pauta, clave e notas em `ink` sobre `panel` branco, para leitura limpa.

## A reconciliar (depois)

A rampa de "heat" do combo em `03-recompensa-e-momentum.md`
(cinza → teal → azul → coral → ouro) foi definida antes da paleta. Harmonizar as
duas — ex.: usar `accent2` (teal) como degrau base e escolher um topo que converse
com o índigo — quando formos detalhar o áudio/momentum.
